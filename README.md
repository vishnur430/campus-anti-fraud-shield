# 🛡️ Campus Anti-Fraud Shield

A multi-modal system designed to protect students from hybrid cyber-phishing and AI voice scams.

## Key Features
- **Form & Email Risk Analyzer:** Scans application form URLs and recruiter email metadata to catch free-hosted forms and generic email domains.
- **AI Voice Deepfake Verifier:** Leverages fine-tuned Wav2Vec2 models to detect synthetic voice artifacts in call audio.
